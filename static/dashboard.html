🚀 Getting Started with Instagram Creator API

Follow these steps to connect your official Instagram account to the bot:

  1. Convert to Creator/Business Account:
    Open Instagram App, go to Settings & Privacy -> Creator/Business tools -> switch to a Creator or Business account.
  2. Enable Message Access (Crucial Mobile Setting):
    In your Instagram mobile app, go to Settings and Privacy -> Messages and Story Replies -> Message Controls. Under Connected Tools, toggle "Allow Access to Messages" to ON. Without this, Meta will block all replies.
  3. Link Instagram to a Facebook Page:
    Create a Facebook Page and link your Instagram account via the Page settings.
  4. Create a Facebook Developer App:
    Go to the Facebook Developers Portal, create a new app, select Other -> Business.
  5. Add Instagram Graph API Product:
    In your app dashboard, find and add Instagram Graph API.
  6. Generate Page Access Token & Extend it:
    Use the Graph API Explorer to generate a token for your connected Facebook Page. Ensure these permissions are checked:
    instagram_basic, instagram_manage_messages, pages_manage_metadata, pages_show_list
    To prevent token expiration in 2 hours: Click the **ⓘ Info** icon next to the generated access token, click **Open in Access Token Tool**, then click **Extend Access Token** to get a 60-day long-lived token.
    Copy this token into the **Access Token** field.
  7. Configure Webhooks:
    Copy the Webhook URL and Webhook Verify Token from this dashboard.
    Paste them into the Instagram Webhook section of your Facebook Developer App.
    Subscribe to the messages event.
